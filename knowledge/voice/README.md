# voice/: how James writes

Drop 5–10 of your best **real** emails here, one file each (`.md` or `.txt`). A good mix:
- 3–4 first-touch emails that got replies
- 2–3 follow-ups
- 1–2 re-engagement emails to past sponsors
- 1 reply to a "send me the prospectus" response

Format (optional but helpful):
```
Context: first touch, BD contact, workplace tech, got a reply
Subject: ...

Body...
```
Remove anything confidential (prices agreed, private details). The drafter copies tone, length, greeting and sign-off style. It does not copy content.
